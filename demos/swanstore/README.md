# سوان ستور — swanstore

متجر **عرض** (Display store) لمستلزمات الموسيقى: فاينل، ملابس، إكسسوارات، ملصقات ومستلزمات عزف.
لا توجد سلة تسوّق ولا دفع إلكتروني — الزائر يتصفّح القطعة ثم يطلبها مباشرة عبر واتساب أو الهاتف أو إنستغرام.

الموقع كله **HTML/CSS/JS خام** بدون أي إطار عمل أو خطوة بناء (no build step)، ولوحة تحكم PHP بسيطة
تكتب البيانات في ملف JSON واحد.

---

## البنية

```
index.html              الصفحة الرئيسية (هيرو، تصنيفات، مختارات، المتجر، لماذا نحن، من نحن، تواصل)
product.html            صفحة المنتج (?id=...) + منتجات مشابهة
data/products.json      قاعدة البيانات الوحيدة — تُدار من لوحة التحكم
assets/css/style.css    نظام التصميم بالكامل (تُستخدم متغيراته في لوحة التحكم أيضًا)
assets/js/main.js       سلوك الموقع + طبقة البيانات (Swanstore.*)
assets/img/logo.jpg     شعار المتجر (مقصوص من الأصل المحفوظ في logo-original.jpg)
assets/img/products/    صور المنتجات المرفوعة من لوحة التحكم
admin/                  لوحة التحكم (PHP): دخول، قائمة منتجات، إضافة/تعديل/حذف، تبديل التوفر
```

## التشغيل محليًا

لوحة التحكم تحتاج PHP، والواجهة تحتاج خادمًا محليًا (لأن المنتجات تُجلب عبر `fetch`):

```bash
php -S localhost:8000
```

ثم:

- الموقع: <http://localhost:8000/>
- لوحة التحكم: <http://localhost:8000/admin/login.php>

إذا أردت معاينة الواجهة فقط دون PHP:

```bash
python3 -m http.server 8000
```

> ⚠️ اسم المستخدم الافتراضي هو `admin` ولا تزال كلمة المرور الافتراضية فعّالة
> (`isDefault: true` في `admin/data/admin.json`). **غيّرها من صفحة «الحساب» قبل رفع الموقع.**

## تعديل بيانات التواصل

كل أرقام وحسابات المتجر في مكان واحد — أعلى `assets/js/main.js`:

```js
R.CONTACT = {
  whatsappNumber: '9647500000000',   // أرقام فقط بدون + — تُستخدم في روابط wa.me
  phoneDisplay:   '+964 750 000 0000',
  phoneTel:       '+9647500000000',
  instagramHandle:'@swanstore.iq',
  instagramUrl:   'https://instagram.com/swanstore.iq'
};
```

تغييرها هنا يحدّث الهيدر والفوتر وبطاقات التواصل وأزرار الطلب في صفحات المنتجات كلها دفعة واحدة.
بعد استبدال الأرقام الحقيقية، احذف سطر التنويه «جميع بيانات التواصل أعلاه مؤقتة» من `index.html`.

## شكل المنتج في `data/products.json`

```json
{
  "id": "p_a1b2c3d4e5f6",
  "category": "ملابس",
  "icon": "shirt",
  "image": "assets/img/products/xxx.jpg",
  "name": "تيشيرت — عصر الروك",
  "price": 25000,
  "tag": "الأكثر طلبًا",
  "description": "...",
  "inStock": true
}
```

- `category` — نص حر. أي تصنيف جديد يظهر تلقائيًا في التصنيفات وفي فلاتر المتجر وفي الفوتر.
- `icon` — أحد: `vinyl` | `shirt` | `pendant` | `poster` | `guitar`.
- `image` — `null` تعني أن الموقع يرسم **غلافًا مولّدًا** للقطعة (تدرّج + أيقونة التصنيف + نقاط هافتون)
  بدل صورة مفقودة، ويختلف ميلان التدرّج من منتج لآخر حسب `id`.
- `tag` — شارة صغيرة اختيارية فوق الصورة (مثال: «جديد»، «إصدار محدود»).
- `inStock: false` — تُعرض القطعة بالأبيض والأسود مع شارة «غير متوفر»، ويتحوّل زر الطلب إلى
  «اسأل عن موعد التوفر».

المنتجات الحالية **بيانات عرض تجريبية** لملء التصميم — احذفها من لوحة التحكم عند إدخال المخزون الحقيقي.

## نظام التصميم

الاتجاه: *مسرح ليلي* — خلفية سوداء، ورق عظمي (`--bone`) مأخوذ من لون شعار المتجر، ولون كاشف قرمزي واحد.

| المتغيّر | الاستخدام |
|---|---|
| `--ink-900 … --ink-500` | خلفية الصفحة ثم الأسطح المرتفعة |
| `--bone` / `--bone-2` / `--bone-3` | العناوين / نص الفقرات / نص ثانوي وزخرفي |
| `--accent` / `--accent-hi` | اللون الكاشف والتفاعل عليه |
| `--f-display` | Noto Kufi Arabic — العناوين |
| `--f-body` | IBM Plex Sans Arabic — النصوص |
| `--f-latin` | Bebas Neue — الأرقام والعناوين اللاتينية الصغيرة |

الحركة كلها محكومة بـ `prefers-reduced-motion`: إن فعّل المستخدم تقليل الحركة تتوقف الحبيبات
والدوران والكشف عند التمرير فورًا. الأزرار وحقول النماذج (`.btn` و `.field`) مشتركة بين الموقع
ولوحة التحكم، فأي تعديل عليها ينعكس على الاثنين.

## ملاحظات

- الشعار الأصلي كان لقطة شاشة كاملة؛ تم قصّه إلى القرص وحده والاحتفاظ بالنسخة الأصلية في
  `assets/img/logo-original.jpg`.
- البحث يعالج الاختلافات الإملائية العربية (الهمزات، التاء المربوطة، الألف المقصورة، التشكيل)
  ويقترح أقرب المنتجات عند عدم وجود نتيجة. يُفتح بأيقونة البحث أو بـ <kbd>Ctrl</kbd>+<kbd>K</kbd>.
- لا يوجد اعتماد خارجي سوى خطوط Google Fonts.
